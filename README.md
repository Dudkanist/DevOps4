# REST API для управления списком задач (todo-api)

Простой Python-сервис на базе Flask, предоставляющий REST API для управления списком задач. В проекте полностью настроен и успешно протестирован автоматизированный CI/CD пайплайн повышенной сложности (**Вариант 2**).

## Основные возможности CI/CD пайплайна
* **Качество кода (Lint):** Автоматическая проверка стиля кода с помощью `flake8` (максимальная длина строки расширена до 120 символов).
* **Матричное тестирование (Test):** Параллельный запуск тестов (`pytest` + `pytest-cov`) на трех версиях среды: Python 3.10, 3.11 и 3.12.
* **Сборка (Build):** Автоматическое создание Docker-образа при пуше в целевые ветки и сохранение его структуры.
* **Безопасность (SBOM):** Сканирование собранного образа утилитой `Syft` (v1.4.1) и генерация отчетов о зависимостях в форматах CycloneDX и SPDX JSON со сроком хранения артефактов 90 дней.
* **Поставка (Deploy):** Раздельные окружения для Staging (автоматически для ветки develop) и Production (ручной запуск по тегу).

## Важное примечание: Перенос пайплайна на GitHub Actions

В соответствии с описанием лабораторной работы, в качестве альтернативной платформы автоматизации был выбран **GitHub Actions** (конфигурация находится в `.github/workflows/main.yml`).

Перенос пайплайна с GitLab CI/CD был обусловлен критическими инфраструктурными ограничениями публичного облака `gitlab.com`:

1. **Политика верификации:** Платформа GitLab ввела жесткие региональные ограничения и не отправляет SMS-подтверждения на российские номера телефонов при регистрации воркеров.
2. **Финансовая политика:** Для активации бесплатных вычислительных мощностей (Shared Runners) сервис теперь требует обязательного ввода данных банковской карты. Предоставление личных платежных данных на сторонней зарубежной платформе в рамках выполнения учебного задания нецелесообразно из соображений информационной безопасности.

Вся архитектура и строгая логика этапов, описанная в **Варианте 2** (включая матрицы, условия `rules`, сборку SBOM и выгрузку артефактов), были бережно перенесены на синтаксис GitHub Actions. Пайплайн успешно отрабатывает в автоматическом режиме (статус: `Success`).
